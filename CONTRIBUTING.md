# Contribuir

Usa pull requests pequenos e descreve o público, a jogabilidade, os testes e todas as fontes dos recursos. Não incluas publicidade, compras no ambiente infantil, rastreadores, chat livre, recolha de dados pessoais, conteúdos impróprios ou propriedade intelectual sem autorização.

Antes de enviar, executa `node scripts/validate.mjs` e testa em telemóvel nas duas orientações.
