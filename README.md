# DinoJam

Liberta veículos na direção das setas, transporta passageiros por cor e resolve 30 parques cheios.

Jogo independente para a plataforma [DinoPlay](https://rjcferreira.github.io/dino-color-quiz/).

## Desenvolvimento

```bash
node scripts/validate.mjs
python -m http.server 8080
```

Todos os recursos funcionam offline. Alterações entram por pull request e só versões revistas podem integrar o catálogo oficial.
